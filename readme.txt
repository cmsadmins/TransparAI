Label AI-generated media: visible badge, machine-readable IPTC/XMP in the files, and automatic detection via C2PA, XMP/IPTC and generator signatures.

== Description ==

TransparAI covers both halves of AI media transparency (EU AI Act, Article 50) — and finds your AI media by itself:

**Automatic detection**

* **Scans every upload and your existing library** for AI provenance signals: C2PA/Content Credentials manifests (JPEG, PNG, WebP, MP4/MOV, AVIF/HEIC), the IPTC `DigitalSourceType` declaration in XMP and IPTC-IIM, Stable Diffusion / ComfyUI / NovelAI / InvokeAI parameter chunks in PNG files, generator names in EXIF and XMP written by Midjourney, DALL-E, Adobe Firefly, Leonardo, Ideogram, Flux and others, and the ID3 "aigc" declaration in MP3 files.
* **Structural parsing instead of blind text search.** TransparAI parses the actual containers (JPEG segments, PNG chunks, RIFF, ISO-BMFF boxes, ID3 frames) and matches only inside real metadata blocks with word boundaries — so a Spanish photo caption containing "imagenes" never triggers a false positive.
* **Confidence levels with a review queue.** Files that explicitly declare AI origin can be labeled automatically; strong-but-informal signals land in a review queue where you confirm or dismiss them — in bulk. Cameras like Leica and Sony also embed Content Credentials into real photos, so a C2PA manifest alone never auto-labels.
* Media generated by AI plugins on your own site (AI Engine, AI Power, Elementor AI, WordPress AI) is labeled at the source.

**Visible labeling**

* A configurable badge on labeled media in the front end: overlay or caption line, four positions, three sizes, dark/light/outline/icon-only styles, optional generator name, optional alt-text note for screen readers.
* Works with the block editor (images, galleries, covers, featured images, video and audio blocks), the classic editor, template-driven images, text widgets and Elementor (including Theme Builder templates). Badges are rendered server-side, so they survive page caching. CSS background images can be labeled too (optional).

**Machine-readable labeling**

* Writes the IPTC digital source type `trainedAlgorithmicMedia` (or `compositeWithTrainedAlgorithmicMedia` for AI-edited media) as XMP directly into JPEG, PNG and WebP files — including every size variant. Google reads this field and can show an AI notice for your images in image search.
* Existing metadata is preserved: TransparAI merges into existing XMP packets instead of replacing them, marks its own additions, and removes exactly what it wrote when you unlabel a file. Files are replaced atomically and validated first, so a failed write can never corrupt an image.
* **Auto-repair:** image optimizers and thumbnail regeneration often strip metadata. TransparAI fingerprints the files of labeled media and restores missing declarations automatically (hourly integrity sweep).

**For agencies and large libraries**

* WP-CLI: `wp transparai scan`, `flag`, `unflag`, `status --format=csv` (audit export), `write-meta`, `verify-meta --repair`.
* Batched library scan with progress bar, pause and resume; per-file evidence stored for every detection.
* Public API: `do_action( 'transparai_mark_ai', $attachment_id, 'My Generator' );` and filters for custom detection rules.

The plugin runs entirely on your server. It makes no external requests, loads nothing from third-party servers and collects no data.

**Background:** Article 50 of the EU AI Act (Regulation (EU) 2024/1689) introduces transparency obligations for AI-generated content, applying from 2 August 2026. This plugin provides the technical building blocks for labeling AI-generated media: automatic discovery, a visible disclosure and a machine-readable marking following the IPTC standard. Whether and how the obligations apply to your website remains your responsibility; this plugin is a technical tool, not legal advice.

== Frequently Asked Questions ==

= Can the plugin detect every AI image? =

No — and no plugin can. Detection relies on metadata that generators embed. Images whose metadata was stripped (social media re-uploads, screenshots, clipboard pastes) carry no signals. Invisible pixel watermarks such as Google SynthID can only be verified by the vendor's own service; TransparAI does not pretend otherwise. Detected metadata is an indication, not cryptographic proof — a review queue exists for exactly that reason.

= Does the plugin change my image files? =

Only when a file is labeled and the metadata option is enabled: the plugin then writes a small XMP block into the JPEG, PNG or WebP file (and its size variants). The image pixels are untouched. Files are replaced atomically and validated first. Unlabeling removes exactly the metadata this plugin wrote; foreign metadata is never touched.

= Why was a real camera photo put into the review queue? =

Modern cameras (Leica, Sony, Nikon) embed C2PA Content Credentials into real photos. A C2PA manifest alone therefore never auto-labels — it lands in the review queue unless the manifest declares an AI source. You can dismiss it with one click; dismissed files are not re-queued.

= Which page builders and editors are supported? =

The visible badge covers the block editor (image, gallery, cover, media-text, featured image, video and audio blocks), the classic editor, template images, text widgets and Elementor including Theme Builder templates. The machine-readable XMP labeling is independent of any builder and always works.

= Does the plugin phone home? =

No. There are no external requests of any kind — no APIs, no CDNs, no telemetry. All detection happens by reading file bytes locally.

= What happens when I uninstall the plugin? =

By default your labels stay in the database (reinstalling restores them) and metadata already written stays in the files. If you prefer a full cleanup, enable "Delete all plugin data" in the settings before uninstalling; unlabel files first if you also want the in-file metadata removed.

= Can I label media programmatically? =

Yes. The meta key `_transparai_ai` is registered for the REST API, WP-CLI commands cover bulk work, and other plugins can call `do_action( 'transparai_mark_ai', $attachment_id, 'Generator name' )`.

== External services ==

None. The plugin makes no requests to external services.

== Privacy ==

TransparAI processes media files locally on your server and stores its results in the WordPress database (attachment meta and one settings option). It does not collect, transmit or share any data, and it sets no cookies.
